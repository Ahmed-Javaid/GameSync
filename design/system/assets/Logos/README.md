# Logos

`gamesync-mark.svg` is the GameSync mark: two overlapping rounded squares, one per PC, drawn at a 2px stroke on a 24px grid in the default `primary` (#7fe6f2, Arcade's cyan). In the app, the rail's mark takes the current theme's `primary`; this file stays cyan. Use it at 22px on the side rail and at 16px as the window icon. Place it on `bg-100` or darker only. There is no wordmark: set the name "GameSync" in `sans` at weight 600.
