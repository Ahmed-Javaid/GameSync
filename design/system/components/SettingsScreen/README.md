Showcase of Settings. Appearance re-themes the whole screen live as you pick a surface, mode, preset or colour; the Surface (Glossy or Solid) is the one every screen in this system follows; Storage and folders shows the backup folder (press Change… to watch a move), history to keep, game folders, extra save folders and where shared zips go. Backup and sync holds **What to back up**, the defaults every new game starts from: game saves always; settings files (Sync between PCs, Back up on this PC, Don't back up); screenshots; Skip logs, crash dumps and caches; and patterns to skip. Changing them offers to apply the change to the games already syncing, which otherwise keep their own. The other sections cover backup time, conflicts, cloud, devices, notifications and safety.
