Showcase of Settings. Appearance re-themes the whole screen live as you pick a surface, mode, preset or colour; the Surface (Glossy or Solid) is the one every screen in this system follows; Storage and folders shows the backup folder (press Change… to watch a move), history to keep, game folders, extra save folders and where shared zips go. Backup and sync starts with **Start GameSync when you sign in**, then the daily backup: its time (Change time opens a field; its switch turns the backup off) and its last run with **Run now**. It holds **What to back up**, the defaults every new game starts from: game saves always; settings files (Sync between PCs, Back up on this PC, Don't back up); screenshots; Skip logs, crash dumps and caches; and patterns to skip. Changing them, or the conflict default under **When two PCs disagree**, offers to apply the change to the games already syncing, which otherwise keep their own. Cloud has three states: Google Drive, signed in as the account, with Open folder in Drive and Sign out (signed out, it offers Sign in with Google); a folder every PC points at (`#cloud-folder`); and no cloud yet, with Connect the cloud (`#cloud-none`). Devices lists every PC with its GameSync version and when it was last seen; only this PC has Rename, since each PC names itself and the others see the new name after its next sync. The foot of the settings column has the version and **Copy diagnostics**, for a bug report: the logs and each game's versions, never the sign-in or the saves. **Achievements** (version 35; the owner, 3 Oct 2026, ACH-09, ACH-10) sets what you see and hear when you unlock one while playing: the popup (GameSync's own small window over the game, never taking focus or a click) and its sound, each with its switch; the **Sound**, one of five GameSync makes itself (Soft bell, Marimba, Glass, Harp, Pop), picking one playing it, with Hear it beside it, and its **Volume** (Quiet, Soft, Medium, Loud; Soft unless changed, every one softer than the first chime, which the owner found too loud; version 37); the corner it shows in; and **Try the popup**, now or in 10 seconds so you can switch to a game first (`#achievements`). Under it, **Games** (version 41; the owner, 4 Oct 2026: "Game in your achievements makes no sense. Also it needs to be either a popup or a new window that shows all the games in the achievement system"): one row, **Achievements by game**, saying how many games count and how many have GameSync's popup, with **Choose games…**, which opens `AchievementGamesDialog` over the page (`#achievements-games`): every game whose achievements GameSync reads, each with Counts and GameSync's popup. Version 37's For games Steam runs switch is gone: a game a launcher runs (Steam, Epic, Ubisoft Connect, the EA app, GOG Galaxy, Xbox) has GameSync's popup off until it's turned on there, as the launcher shows its own (the owner: "games on steam/epic/official external launchers have their own achievement popups, so those games will have their popups turned off by default on gamesync"). **Copies Steam doesn't run** (version 48, KAN-123; the owner, 4 Oct 2026: "As long as my offline games also have achievements"): a `FolderList` of folders where such copies keep their own record of what's unlocked, one folder per game named by its Steam number with the record inside, each folder saying how many of your games have records there (`#achievements`; none added, `#achievements-none`). Kept on this PC only; GameSync only reads the records, and names each achievement from Steam's list, so those games count on the Achievements page and Home like Steam's and are listed in Achievements by game, with GameSync's popup on, as no launcher shows one. Where such records live is the person's to add: no list of them comes with GameSync. With none added, a copy that isn't Steam's has only Steam's list at 0 on its page, which counts nowhere and isn't listed. Light mode has its own Glossy since version 35, so the Surface row reads the same in both modes. The other sections cover notifications and safety; Safety's **Let learn mode ask for admin** comes after v1 with the tracer (the owner, 7 Oct 2026: "yes, per-user install and tracer after v1"), tagged so and greyed here, and the app shows nothing for it until then.

**Updates** (version 53; the owner, 7 Oct 2026: no paid code signing, and "yes, per-user install and tracer after v1"): GameSync asks GitHub for its latest release once a day and gets a newer one ready in the background; it installs only when the person restarts GameSync, and only once GameSync's own release signature checks out. The card is named for the version this PC runs, and says it's installed for this person alone in `%LOCALAPPDATA%\Programs\GameSync`. Its states: **ready** (`#updates`): "GameSync 1.0.1 is ready" with **Restart to update** as the primary, which closes GameSync, installs it and opens it again in a few seconds, then "What's new in 1.0.1" from the release notes and Release notes on GitHub; **up to date** (`#updates-latest`): when it last checked, with Check now; **downloading** (`#updates-downloading`): a bar with how much, how fast and how long; **refused** (`#updates-refused`): in warn, that it didn't pass GameSync's own check and nothing was installed, with Try again; and **offline** (`#updates-offline`): that GitHub couldn't be reached, with Check now. Then **Check for updates every day** (on by default; off, Check now still works) and a note that GameSync isn't code-signed, so Windows may warn the first time it runs, while every update is checked against GameSync's own signature and anything else refused. Restart to update waits while a game that syncs is running, saying so in its tooltip. Home's top bar shows the same Restart to update while one is ready (LauncherScreen `#update`), and so does the tray's menu.
