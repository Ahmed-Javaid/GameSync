Showcase of Settings. Appearance re-themes the whole screen live as you pick a surface, mode, preset or colour; the Surface (Glossy or Solid) is the one every screen in this system follows; Storage and folders shows the backup folder (press Change… to watch a move), history to keep, game folders, extra save folders and where shared zips go. Backup and sync starts with **Start GameSync when you sign in**, then the daily backup: its time (Change time opens a field; its switch turns the backup off) and its last run with **Run now**. It holds **What to back up**, the defaults every new game starts from: game saves always; settings files (Sync between PCs, Back up on this PC, Don't back up); screenshots; Skip logs, crash dumps and caches; and patterns to skip. Changing them, or the conflict default under **When two PCs disagree**, offers to apply the change to the games already syncing, which otherwise keep their own. Cloud has three states: Google Drive, signed in as the account, with Open folder in Drive and Sign out (signed out, it offers Sign in with Google); a folder every PC points at (`#cloud-folder`); and no cloud yet, with Connect the cloud (`#cloud-none`). Devices lists every PC with its GameSync version and when it was last seen; only this PC has Rename, since each PC names itself and the others see the new name after its next sync. The foot of the settings column has the version and **Copy diagnostics**, for a bug report: the logs and each game's versions, never the sign-in or the saves. **Achievements** (version 35; the owner, 3 Oct 2026, ACH-09, ACH-10) sets what you see and hear when you unlock one while playing: the popup (GameSync's own small window over the game, never taking focus or a click) and its sound, each with its switch; the **Sound**, one of five GameSync makes itself (Soft bell, Marimba, Glass, Harp, Pop), picking one playing it, with Hear it beside it, and its **Volume** (Quiet, Soft, Medium, Loud; Soft unless changed, every one softer than the first chime, which the owner found too loud; version 37); the corner it shows in; and **Try the popup**, now or in 10 seconds so you can switch to a game first (`#achievements`). Under it, **Games** (version 41; the owner, 4 Oct 2026: "Game in your achievements makes no sense. Also it needs to be either a popup or a new window that shows all the games in the achievement system"): one row, **Achievements by game**, saying how many games count and how many have GameSync's popup, with **Choose games…**, which opens `AchievementGamesDialog` over the page (`#achievements-games`): every game whose achievements GameSync reads, each with Counts and GameSync's popup. Version 37's For games Steam runs switch is gone: a game a launcher runs (Steam, Epic, Ubisoft Connect, the EA app, GOG Galaxy, Xbox) has GameSync's popup off until it's turned on there, as the launcher shows its own (the owner: "games on steam/epic/official external launchers have their own achievement popups, so those games will have their popups turned off by default on gamesync"). **Kept by GameSync** (version 54; the owner, 8 Oct 2026: "The achievement system needs to work even without steam. It can get information about WHAT achievements are there to begin with, but after that it needs to work without it", then yes to keeping it in the Drive folder) comes first on the page: what's unlocked is GameSync's own record, every unlock it sees kept with its day whether Steam, the copy or the PC is still there or not, and **Keep them in the cloud** (on once a cloud is connected; off, kept on this PC only): every PC shows the same achievements, kept in GameSync's folder on Google Drive beside the saves (or the cloud folder); its note says GameSync sees unlocks in Steam's files on any of your PCs and in the records copies keep themselves, which it finds by itself, and that a copy that writes nothing down has them marked on its page. With no cloud connected the row is off and says Connect the cloud first. **Copies Steam doesn't run** (version 48, KAN-123; the owner, 4 Oct 2026: "As long as my offline games also have achievements"; since version 54, "Tracking by itself", then "find them itself"): **GameSync finds the records such copies keep of what's unlocked by itself**, in AppData, Documents, Public Documents and each game's own folder, and while a game plays, knowing a record by the game's achievements named inside it, so no list of where such records live comes with GameSync. The card says how many it found, with **Look again** (busy while looking) and when it last looked, then each record found (its path, its game and how far it is); then **Other folders**, a `FolderList` for records kept anywhere else (a folder with one folder per game, named by its Steam number), with Add a folder (`#achievements`; none found or added, `#achievements-none`, which says a copy that writes nothing down can have its achievements marked on its page). GameSync only reads the records, and names each achievement from Steam's list, so those games count on the Achievements page and Home like Steam's and are listed in Achievements by game, with GameSync's popup on, as no launcher shows one. Light mode has its own Glossy since version 35, so the Surface row reads the same in both modes. The other sections cover notifications and safety; Safety's **Let learn mode ask for admin** comes after v1 with the tracer (the owner, 7 Oct 2026: "yes, per-user install and tracer after v1"), tagged so and greyed here, and the app shows nothing for it until then.

**Updates** (version 53; the owner, 7 Oct 2026: no paid code signing, and "yes, per-user install and tracer after v1"): GameSync asks GitHub for its latest release once a day and gets a newer one ready in the background; it installs only when the person restarts GameSync, and only once GameSync's own release signature checks out. The card is named for the version this PC runs, and says it's installed for this person alone in `%LOCALAPPDATA%\Programs\GameSync`. Its states: **ready** (`#updates`): "GameSync 1.0.1 is ready" with **Restart to update** as the primary, which closes GameSync, installs it and opens it again in a few seconds, then "What's new in 1.0.1" from the release notes and Release notes on GitHub; **up to date** (`#updates-latest`): when it last checked, with Check now; **downloading** (`#updates-downloading`): a bar with how much, how fast and how long; **refused** (`#updates-refused`): in warn, that it didn't pass GameSync's own check and nothing was installed, with Try again; and **offline** (`#updates-offline`): that GitHub couldn't be reached, with Check now. Then **Check for updates every day** (on by default; off, Check now still works) and a note that GameSync isn't code-signed, so Windows may warn the first time it runs, while every update is checked against GameSync's own signature and anything else refused. Restart to update waits while a game that syncs is running, saying so in its tooltip. Home's top bar shows the same Restart to update while one is ready (LauncherScreen `#update`), and so does the tray's menu.

**Rarity** (version 55; the owner, 8 Oct 2026: "Refresh rarity shouldn't be on the main achievements page, but in settings"): a card in Achievements, after Games. How rare each one is: the share of Steam's players who have each achievement, which sets its tier; GameSync asks Steam once a week by itself. **Refresh now** asks again for every game with achievements ("Asking Steam" while it does), then says what it came to ("Asked Steam again for 23 games."). It was Refresh rarity on the Achievements page until version 55.

**Version 57**: **Install updates when GameSync starts with Windows** (built; the owner, 9 Oct 2026: yes, so friends never have to click), under Check for updates every day, on by default: a ready update installs as GameSync starts at sign-in, before any game is played, in a few seconds; off, it waits for Restart to update (`#updates`). **Motion** (`#appearance-still`; a friend: "Some user dont have animations?"): GameSync follows Windows' Animation effects, so with them off nothing moves and looks change at once; Appearance then starts with a Motion card saying so, with Open Visual effects. **Report a problem…** (`#report`; a friend: "add a report a bug tool"), primary, above Copy diagnostics at the foot of the column: a dialog for what happened in the person's words, with Add the diagnostics (ticked: the logs and each game's versions, never the sign-in or the saves); Open on GitHub opens a new issue on GameSync's GitHub with both filled in, and nothing leaves the PC until they post it there; without a GitHub account, Copy diagnostics is the way.

**Built** (version 58, 18 Oct 2026; KAN-168, KAN-169): **Motion** shows while Windows' Animation effects are off, read again whenever the page reads its settings, and Open Visual effects opens Windows' own page for it. **Report a problem…** opens its dialog over Settings; Open on GitHub opens GameSync's new issue with the first line as its title and the person's words in its body, and puts the diagnostics on the clipboard to paste under Diagnostics, since a link holds only a couple of thousand characters and the logs run far longer (words too long for one link go on the clipboard too, the whole report). So the dialog says "the diagnostics ready to paste in", and "Nothing is posted until you submit the issue on GitHub", rather than that nothing leaves the PC: the browser asks GitHub for the page with the words in its address. Done says what's on the clipboard and to press Submit new issue there.
