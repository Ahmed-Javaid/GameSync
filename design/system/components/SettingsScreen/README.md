Showcase of Settings. Appearance re-themes the whole screen live as you pick a surface, mode, preset or colour; the Surface (Glossy or Solid) is the one every screen in this system follows; Storage and folders shows the backup folder (press Change… to watch a move), history to keep, game folders, extra save folders and where shared zips go. Backup and sync starts with **Start GameSync when you sign in**, then the daily backup: its time (Change time opens a field; its switch turns the backup off) and its last run with **Run now**. It holds **What to back up**, the defaults every new game starts from: game saves always; settings files (Sync between PCs, Back up on this PC, Don't back up); screenshots; Skip logs, crash dumps and caches; and patterns to skip. Changing them, or the conflict default under **When two PCs disagree**, offers to apply the change to the games already syncing, which otherwise keep their own. Cloud has three states: Google Drive, signed in as the account, with Open folder in Drive and Sign out (signed out, it offers Sign in with Google); a folder every PC points at (`#cloud-folder`); and no cloud yet, with Connect the cloud (`#cloud-none`). Devices lists every PC with its GameSync version and when it was last seen; only this PC has Rename, since each PC names itself and the others see the new name after its next sync. The foot of the settings column has the version and **Copy diagnostics**, for a bug report: the logs and each game's versions, never the sign-in or the saves. The other sections cover notifications and safety.
