Showcase of one game's saves in the save manager: everything about a game's saves that used to be on its page. It opens from the game's row in the save manager's table, Open in Saves on the game's page, a status's own action (Review, See where, See why), and a Needs you row's button on Home; Resolve opens the game's conflict. Back returns to where it was opened from. Built only from the components above.

- **Back** and the breadcrumb (Save manager › the game) at the top left return to every game's saves; Esc, Alt+Left and the mouse's back button do the same.
- The top bar: Import kept saves… (copies of its saves kept by hand become named saves: ImportKeptSavesDialog, BAK-19), **Share…** (its current save, or any named save or version, into a zip a friend can import: ShareSavesDialog with this game ticked; disabled, saying why, for a game with an anti-cheat or an online mode, R16; KAN-84) and Back up now, which is the primary unless the game needs you. Back up now works while the game runs too, keeping the save as it is then, its upload waiting until the game closes (KAN-91). Choose files… sits with Where the saves are, and New named save… on the Named saves card (the owner, 1 Oct 2026).
- **Status**: the game's one status, what happened in a sentence, and its actions when it needs you: Keep the new save (primary) and Restore the previous save for a held save, Resolve for a conflict (its screen: ConflictScreen), Retry when a file was in use, Add a place… when its saves weren't found. The last conflict GameSync settled shows in a line under it while its winner is the current save ("Newest kept: DESKTOP's save is current, LAPTOP's is pinned in history."), with See both (the conflict screen, settled) and Swap to LAPTOP's, which asks first like a restore (`#terraria` shows it).
- **Named saves** (`#many`: Bloodborne GOTY's 36; the owner, 1 Oct 2026, KAN-82, KAN-83, KAN-85, KAN-87): the count in the heading ("Named saves · 36"); a search, Find a named save, and a sort, Newest first (the default) or Name, kept per PC (`#many-find`); and the list keeps the card's height, scrolling inside it, so 36 don't make a long page. A row is its name, when and on which PC, then Restore (or In place, for the one whose files are the game's now), Export (a zip, through the share window, as the history's Export) and ⋯. No pin: every named save is pinned, so it said nothing and looked like a button; pins stay in the history, where they tell versions apart, with the tooltip "Kept forever: never thinned". ⋯ (`#many-where`) floats over the list: Rename (a box with its name, Enter or Rename); **Where it's kept**: in GameSync's history, its files stored once by their contents in the backup folder on this PC and in Google Drive, so saves that share files take their space once, with no folder of its own; **Export as a folder…** copies its files into a folder the person picks, named after it, laid out as the game keeps them; Open the backup folder; and Remove the name (the save stays in the history, where it comes back like any version). The card's own New named save… opens NamedSaveDialog (`#named`): what's kept, its name, Keep this save (since 1 Oct 2026, the owner: like Add a place, not a small grey box); None yet says what it's for. On a game not syncing yet, it and Import kept saves… say first that GameSync starts keeping its saves, backed up but not synced between PCs, with the files and size it starts with.
- **Restore asks first** (KAN-89): "Restore Bloodborne GOTY's save to “befo ludwig”?", when and on which PC it was saved, that the current save is kept first, Cancel and Restore; while the game runs, a line in `warn` that the save may need loading again from its menu and that the game may write over it as it quits (KAN-91).
- **Where the saves are**: each place as this PC has it, in `mono`, and under it what's kept there in words: "The folder SPRJ0005 and everything in it", with its files, size and newest date as they're kept, never the scan's whole-folder numbers (the owner, 1 Oct 2026, KAN-81: SPRJ0005, not CUSA00207 around it); Open the folder and Choose files…; Add a place… sets one by hand (AddPlaceDialog, FOLD-01). **A program in a save folder** (version 51, R1 and R2; `#wukong-program`): a program file found in a place is never backed up, and the place says so under its numbers in `warn`: "A program is in this folder and isn't backed up: Uninstall.exe. Programs never travel with saves; if you didn't put it there, check where it came from." (with "and 2 more" for several). The game's log says it once, in `warn`, when a program is first found there ("Left out Uninstall.exe: a program, never backed up or synced"), not at every backup; it isn't a status of its own, as the saves still sync.
- **Current save** (KAN-92, from the owner's drawing under Where the saves are): the live save as the game has it now: Last written (its newest file), Size (files and MB), Backed up (when, and where: on this PC and in Google Drive; or that it changed since, or is held for review), and Same as a named save or version when its files are the same ("“befo ludwig”, restored today 20:52"). Facts only: Back up now and New named save… stay where they are, once on the page.
- **While it uploads or downloads** (`#uploading`, KAN-80): a boxed `JobProgress` under the status, "Uploading to Google Drive", with how much of how much, how many files, the speed and the time left; "Downloading from Google Drive" when another PC's save comes down. It stays while the upload runs, whether or not the dialog that started it is still open, pauses (and says so) while a game that syncs is played, says when it'll try again if Google Drive can't be reached, and ends with one line saying what it sent. Everything else on the page works meanwhile: the upload runs beside it (KAN-88), so a restore or a named save doesn't wait for it.
- **Every action says what it does** in its tooltip (KAN-86): Restore "Puts this save in place of your current one; your current save is kept first", Back up now "Keeps a version of the save as it is now, on this PC and in your Google Drive, without waiting for the game to close", Export, Share…, New named save…, Import kept saves…, Choose files…, Add a place…, ⋯ and the status's own actions.
- **Busy buttons** (KAN-80): Back up now says "Backing up…", a named save's or a version's Restore "Restoring…", and Sync these saves "Syncing…", each with its spinner and counting dots from the moment it's pressed; a restore under way says so under the status in a `BusyLine` ("Bringing back “befo ludwig”…"), then that it's in place.
- **History**: every version from every PC (`ConsoleTable`): when, which PC, a note (Current; a pin and the label for named, before-update and conflict versions, the pin saying "Kept forever: never thinned"), the size, and Restore (it asks first, and keeps the files there now as a version) and Export. The game's log (`ConsoleLog`) under it.
- **A game not syncing yet** (`#bloodborne`): its status is Not syncing yet, with what the scan found and Sync these saves as the primary; Import kept saves…, Back up now and New named save… keep it backed up only (KAN-63). When its live save sits beside copies kept by hand (Bloodborne's "Before Orphan\SPRJ0005" beside "SPRJ0005", KAN-61), Where the saves are shows the live save alone, and under it the copies beside it, with how many, where and how big, and Bring them in…; Sync these saves opens KeptCopiesDialog (`#bloodborne-sync`), which syncs only the live save and brings the copies in as named saves in one step (`#bloodborne-backup` is the same from Back up now). Choose files… and Add a place… wait until its saves sync. With no versions yet, the history says so.
- **A game with no saves found yet, and learn mode** (version 43; FIND-04, KAN-134; `#rounds`): first run already says such games are "watched the first time they're played", and this is that. Its status is No saves found yet, saying GameSync hasn't found where it saves and that learn mode watches the next time it's played, from anywhere; the Learn mode card says what it watches (the usual save folders, the game's own folder, Steam's) and that it only notes where files change, never touching the game, with Turn off learn mode; Where the saves are says nothing's known yet, and Add a place… stays in the top bar for someone who knows. **While it's played** (`#rounds-playing`): Playing now, "Learn mode is watching where ROUNDS saves", a spinner and since when. **After** (`#rounds-found`): "Saves found by learn mode", when it watched, and See what it found as the primary, the card listing the likeliest places with their numbers; it opens `LearnModeDialog` (`#rounds-open`). **Nothing seen** (`#rounds-none`): it says so, keeps watching next time, and offers Add a place…. A Windows notification says when it found something ("ROUNDS: learn mode found where it saves"), held while a game is fullscreen like every other. Games with an anti-cheat never get learn mode (R15): their page says so, as Properties does.
