Showcase of first-run setup in four steps: scan this PC, choose games, connect the cloud, backups and startup. Built only from the components above; the steps on the left are a `SettingsNav`, and finished steps take the `check` icon.

- There's no side rail until setup is done. Each step has one primary button, the one that moves on; Back is `ghost`. Nothing syncs until the last step, and the left column says so.
- **Scan this PC** shows what each store holds and the game folders scanned, as a `FolderList` with Add a game folder. The scan only reads.
- **Choose games** groups what was found, each group a `Card` with a checkbox for the whole group: Sync (open, one row per game with its cover, name, save path in `mono` and how it was found: save list, engine rule or name search), Back up only, Probably online-only (unticked), Saves found but game not installed, and No saves found yet (a clock icon instead of a checkbox: those games are watched the first time they're played). The aside brings over Ludusavi (ignore list, custom games, backups kept as named saves) and names the games with an anti-cheat.
- **Connect the cloud**: Sign in with Google is the primary until you're signed in, and Skip for now is `secondary`; once signed in, Continue takes over. A folder (NAS, USB drive, another disk) is the alternative. The laptop joins later by signing in with the same account.
- **Backups and startup**: start GameSync at sign-in and the daily backup time, both on by default. Say that both run as the person, without admin rights, so Windows won't ask for permission. The last button, Start using GameSync, opens the launcher while the first backup runs in the background.
