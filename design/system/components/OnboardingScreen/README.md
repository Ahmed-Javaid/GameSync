Showcase of first-run setup in four steps: scan this PC, choose games, connect the cloud, backups and startup. Built only from the components above; the steps on the left are a `SettingsNav`, and finished steps take the `check` icon.

- There's no side rail until setup is done. Each step has one primary button, the one that moves on; Back is `ghost`. Nothing syncs until the last step, and the left column says so.
- **Scan this PC** starts when the step opens and says how far it has got (`#scanning`: each game's saves, one by one, about a minute on a big library); Choose games waits for it. It shows what each store holds and the game folders scanned, as a `FolderList`; Add a game folder picks one in Windows' folder picker and scans again. The scan only reads.
- **Choose games** takes the full width and groups what was found, each group a `Card` with a checkbox for the whole group: Sync (open, one row per game with its cover, name, save path in `mono` and how it was found: save list, engine rule or name search), Synced by their store (Steam or Epic syncs them between PCs; GameSync keeps a backup of every version), Probably online-only (unticked), Saves found but game not installed, and No saves found yet (a clock icon instead of a checkbox: those games are watched the first time they're played). Last comes Something missing?, with Add a game or folder (a game server's world, say). The anti-cheat note names those games beside Back and Continue. Bringing over Ludusavi stays on the command line.
- In Glossy it takes the glow strength over the last-played game's art, like Settings.
- **Connect the cloud**: Sign in with Google is the primary until you're signed in (`#cloud-signed`), and Skip for now is `secondary`; once signed in, or with a folder chosen, Continue takes over. A folder (NAS, USB drive, another disk) is the alternative: chosen, it reads "Saves go to D:\GameSync" with Ready and Change… (`#cloud-folder`). Skip for now keeps every version on this PC; until a cloud is connected, Home's top bar has Connect the cloud in place of the cloud button (see Connect cloud dialog). The laptop joins later by signing in with the same account.
- **Backups and startup**: start GameSync at sign-in and the daily backup time, both on by default. Change time opens a small time field in place, in 24-hour time, with Save (`#daily-time`). Say that both run as the person, without admin rights, so Windows won't ask for permission. The last button, Start using GameSync, opens the launcher while the first backup runs in the background.
