On/off switch for settings that apply straight away.

Provide `checked`, `onChange(checked)`, a `label` for screen readers (usually the row's title) and `disabled`. Off is a `bg-300` track with a `line-200` edge and an `ink-muted` knob; on fills with `primary` and an `on-primary` knob. Use a `Checkbox` instead when the choice is part of a selection or only takes effect after a button.
