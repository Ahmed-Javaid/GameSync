Dialog for a game whose save folder holds copies kept by hand beside its live save (KAN-61): only the live save syncs, and each copy comes in as a named save, in one step. Bloodborne players keep "Before Orphan\SPRJ0005" beside the live "SPRJ0005"; without it, the whole folder would sync as one save, every copy in every version.

Provide `game`, `live` (`{path, saved, files, bytes}`: the live save as this PC has it), `items` (the copies, as ImportKeptSavesDialog's: `{id, name, saved, files, bytes, same?}`), `skipped`, `wholeBytes` (the whole folder), `mode` (`sync`, or `backup` from Back up now, New named save… or Import kept saves… on a game not syncing yet, KAN-63), `stage` (`review`, `done`), `onSync(bring)`, `onWhole` and `onClose`.

- **Review**: the live save in a well, under "Syncs between your PCs" (or "Backed up, not synced between your PCs"), with its path, when it was saved, its files and size. Then **Bring the N copies beside it in as named saves**, ticked: the copies by name with when each was saved, its files and size, oldest first; one identical to another here says Same as that one and isn't named again. Unticked, they stay in their folders, not backed up, and Import kept saves… brings them in later.
- The foot counts what's kept (the live save and N named saves) and its size, and says the folders stay as they are, and that copies made there later aren't synced (New named save… keeps one in a step).
- The primary syncs (or backs up) the live save and keeps the named saves. **Sync all of it instead** keeps the whole folder as one save, for a folder that isn't what it looks like; its tooltip says how big each version would be.
- **Done**: that the live save syncs now, and where the named saves are (Named saves, on every PC).
- Opens from Sync these saves (a game's saves, its page's Saves card) when the scan found copies beside the live save, and from Back up now, New named save… and Import kept saves… on a game not syncing yet. A game's saves show the copies beside the live save under Where the saves are (GameSavesScreen `#bloodborne`).
