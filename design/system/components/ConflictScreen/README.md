Showcase of a conflict waiting for the person: what happened in one sentence, a suggested choice with its reason, both sides side by side, Compare files and Decide later. Built only from the components above.

- The title names the game and what happened ("Sekiro changed on two PCs"); the line under it says what each PC did and that both copies are safe.
- The suggestion card says which side to keep and why, and why GameSync asked instead of choosing: the game is set to Always ask, it's the first sync on this PC, the newer side lost more than half its files or size, it changed while the game wasn't running, or this PC's clock is off.
- Each side is a `Card`: where it is (This PC, or In the cloud from LAPTOP), the PC in uppercase `mono`, a Newest tag on `secondary-soft`, then when it was saved, its last session and how it started, play since the last sync, size and changed files. The suggested side's Keep button is the one `primary`; the other is `secondary`.
- Compare files opens a `ConsoleTable` of the files that differ, with each side's size and time. Settings files aren't part of the choice: each PC keeps its own.
- Decide later leaves the game in Conflict. Until then it neither uploads nor downloads, and each PC keeps playing its own copy; the footer says so.
- **Resolved by newest wins**: the same screen with the banner "Newest kept: DESKTOP's save is current, LAPTOP's is pinned" and one primary button, Swap to LAPTOP's. The status badge reads Conflict · resolved.
