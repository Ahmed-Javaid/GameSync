Showcase of a conflict waiting for the person: what happened in one sentence, a suggested choice with its reason, both sides side by side, Compare files and Decide later; and, settled, which save was kept, with Swap. Built only from the components above.

- **Back** and the breadcrumb (Save manager › the game › Conflict) at the top left: Back and Decide later return to where it was opened from (Home's Conflicts, the game's page or its saves); the game's name opens its saves. Esc, Alt+Left and the mouse's back button do the same. It opens from every Resolve: the play bar, the status on a game's saves, and Home's Needs you.
- The title names the game and what happened ("Sekiro changed on two PCs"); the line under it says when each PC saved and that both copies are safe.
- The suggestion card says which side to keep and why (the newest save, and the longer play), and why GameSync asked instead of choosing: the game is set to Always ask, both saves came from the same starting point, or this PC's clock is off. When the newest isn't suggested, the why says so instead: it lost more than half of its files or size, or it changed while the game wasn't running. Change for this game opens its Properties, on Sync.
- Each side is a `Card`: where it is (This PC, or In the cloud from LAPTOP), the PC in uppercase `mono`, a Newest tag on `secondary-soft`, then `Facts`: when it was saved, its last session, play since the last sync, size and changed files. Another PC's session shows only when its uploads recorded one since the last sync. The suggested side's Keep button is the one `primary`. Keeping this PC's save uploads it at once; keeping another PC's writes its files here, so it asks first in a small flyout ("Carry on with LAPTOP's save?"), saying this PC's is kept in history and Swap brings it back.
- Compare files opens a `ConsoleTable` of the files that differ, with each side's size and time and what changed (on both PCs, on one, only on one, removed on one). Settings files aren't part of the choice: each PC keeps its own.
- Decide later leaves the game in Conflict. Until then it neither uploads nor downloads, and each PC keeps playing its own copy; the footer says so. While a choice is carried out, a line says so ("Keeping DESKTOP's save…") and the Keep buttons wait.
- **Settled** (`#settled`), by newest wins or by the person: the same screen with Conflict · resolved, "Newest kept: DESKTOP's save" (or "You kept DESKTOP's save"), the sides as Current and Pinned, and one primary button, Swap to LAPTOP's, which asks first like a restore. It stays on offer while the kept save is the current one; once a newer save or a restore replaces it, the history has both. A game's saves show the same in one line under its status, with See both and Swap.
