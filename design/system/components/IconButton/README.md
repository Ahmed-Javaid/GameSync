40px circular button with one icon and a required `label` (used for the tooltip and screen readers).

Set `glass` when it sits on cover art, as on the hero, and `size="sm"` for the 32px version in dense rows (Open in Explorer). Use it for settings, manage-saves, import, close and card chevrons.

`busy` turns its icon while its job runs, and `busyLabel` is its tooltip meanwhile: Home's Sync now turns its arrows while GameSync syncs and says "Syncing…" (KAN-80). With reduced motion it stands still and the tooltip still says so.
