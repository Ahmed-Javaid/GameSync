Connecting the cloud after first run skipped it. It opens from Home's Connect the cloud, the small button that takes the cloud button's place in the top bar while no cloud is connected (see Launcher home, `#nocloud`), and later from Settings, Cloud.

- The same two ways as first run's Connect the cloud step, each a `Card`: Sign in with Google (the primary; it opens the browser, and GameSync asks only for its own folder) or a folder (a NAS, a USB drive, another disk). Once either is connected it says so (`#signed`, `#folder`) and the foot's button reads Done; before, Not now closes it.
- Every version GameSync kept while there was no cloud stays on this PC and goes up in the background once one is connected; nothing is lost by waiting.
- The foot's note says the other PC joins by connecting the same account or folder.
