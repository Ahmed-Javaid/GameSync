Timestamped log in mono: time, a coloured tag, then the message.

Provide `lines` (`{time, level: ok | info | warn | error, tag?, msg}`), `live` to show a blinking prompt at the end, and `grow` to fill the remaining height. `dated` widens the time column for a day and a time ("27 Sep 12:00:31"), as the save manager's Log tab shows them. Error lines get a `danger-soft` row. Write messages in the same plain, per-game voice as the rest of the app.
