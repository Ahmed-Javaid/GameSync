Outlined 24px icon from GameSync's own set; the only icon source for the app.

Provide `name` (see `Icon.names`), optional `size` (default 20) and `label` when the icon stands alone and means something. Without `label` it is hidden from screen readers. `filled` fills the `star`, for a favourite.

`arrowLeft` is Back; `trophy`, achievements; `external`, a link that leaves GameSync (a store page); `file` and `key`, a file and a registry key in a `FileTree`; `settings` is also a game's Properties.

- Do: 20px on the rail, 18px in buttons, 14px in badges.
- Don't: mix in icons from other sets or fill them; only `play`, and the `star` of a favourite, are filled.
