One game's settings, like Steam's Properties. It opens from the gear in the game's `PlayBar`, its More and right-click menus, Properties on its On this PC card, and Choose files… (which opens on Saves). Sections down the left, as in Settings (`SettingsNav`), `SettingsRow`s on the right.

- **General**: the name GameSync shows (a rescan keeps it), Favourite, Show in the library (a hidden game still syncs), and the game's ID for the command line, with Copy. A game with an anti-cheat says so here: it starts only through its launcher, learn mode stays off, and its saves are never shared.
- **Art**: the game's cover (its tile), banner (the top of its page, and Home's when it's the last played) and logo (over the banner, in place of its name), each Steam's or an image of your own: Choose an image… opens Windows' picker, and Use Steam's puts Steam's back. Your own images stay on this PC, never synced or shared; JPEG, PNG or WebP up to 8 MB, checked by their content like Steam's art (ART-08). It opens from the game's More menu too (Change the art…).
- **Launch**: how it starts. A store game starts through its store, so the store's own launch options apply: they show read-only with Open in Steam, and Starting from Steam copies the line to put in Steam's launch options so a start from Steam gets GameSync's check too. A game in its own folder shows its program (Change…) and its launch options in a text field.
- **Installed files**: the folder (Open the folder), its size, the store and app ID (Store page), the build, the engine and how GameSync found it. A game not installed says its saves are still on this PC.
- **Saves**: which files are backed up, as a `FileTree` of the places found or added: tick to back up and sync, untick to keep a file on this PC only. Older versions keep what they had, and nothing is deleted. The line above says how many files and how much. Add a file or folder; Learn mode (never for a game with an anti-cheat). Then Settings files, Screenshots and Skip logs, crash dumps and caches, each starting from the defaults in Settings, Backup and sync.
- A game **not syncing yet** shows what the scan found, its boxes greyed and ticked as syncing would take them, until its saves sync.
- **Sync**: Between your PCs or Back up only (for a game its store syncs), who wins when both PCs changed it (Newest wins, Always ask, This PC wins), and Stop syncing it, which asks first.
- Changes wait for **Save changes**; the foot says how many there are. Cancel, Esc and the close button drop them, asking first when there are some. A game's own choices travel with its saves, so its other PCs take the same files (R8).
