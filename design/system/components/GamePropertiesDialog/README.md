One game's settings, like Steam's Properties. It opens from the gear in the game's `PlayBar`, its More and right-click menus, Properties on its On this PC card, and Choose files… (which opens on Saves). Sections down the left, as in Settings (`SettingsNav`), `SettingsRow`s on the right.

- **General**: the name GameSync shows (a rescan keeps it), Favourite, Show in the library (a hidden game still syncs), and the game's ID for the command line, with Copy. A game with an anti-cheat says so here: it starts only through its launcher, learn mode stays off, and its saves are never shared.
- **Art**: the game's cover (its tile), banner (the top of its page, and Home's when it's the last played) and logo (over the banner, in place of its name), each Steam's or an image of your own: Choose an image… opens Windows' picker, and Use Steam's puts Steam's back. Your own images stay on this PC, never synced or shared; JPEG, PNG or WebP up to 8 MB, checked by their content like Steam's art (ART-08). It opens from the game's More menu too (Change the art…).
- **Launch**: how it starts. A store game starts through its store, so the store's own launch options apply: they show read-only with Open in Steam, and Starting from Steam copies the line to put in Steam's launch options so a start from Steam gets GameSync's check too. A game in its own folder shows its program (Change…) and its launch options in a text field. **A game with an anti-cheat** (version 51, R15) starts only through its store, or, in a folder of its own, through its anti-cheat's own launcher (Easy Anti-Cheat's `start_protected_game.exe`, BattlEye's `_BE` program): the program shows read-only with "Starts through its anti-cheat's launcher", and Change… takes only that launcher. With neither, Play says to start it from its launcher, and GameSync never starts its program itself.
- **Installed files**: the folder (Open the folder), its size, the store and app ID (Store page), the build, the engine and how GameSync found it. A game not installed says its saves are still on this PC.
- **Since version 57** (KAN-167; a friend, 8 Oct 2026: Dark Souls III pointed at Dark Souls' program by mistake, then pointed back, while Installed files still showed the other game's folder, and Locate the game's message showed once and never again): a game in its own folder has **Change…** here, which picks its program and checks it the way Locate the game… does. The check reads the program's own record (its name, its GOG or Steam ID, its save list entry) and the folder: a program that's another game's says so in warn, naming both and what to pick instead ("This is Dark Souls: Remastered's program (DarkSoulsRemastered.exe), not Dark Souls III's. Pick DarkSoulsIII.exe in Dark Souls III's folder."), and a folder another game already has is refused, naming that game (`#files-wrong`); a program that fits says so with a check. The answer stays on the page, on Installed files and the game's On this PC card, until it's changed; Locate the game… says the same in its place.
- **Saves**: which files are backed up, as a `FileTree` of the places found or added: tick to back up and sync, untick to keep a file on this PC only. Older versions keep what they had, and nothing is deleted. The line above says how many files and how much. Add a file or folder; Learn mode (never for a game with an anti-cheat). Then Settings files, Screenshots and Skip logs, crash dumps and caches, each starting from the defaults in Settings, Backup and sync.
- A game **not syncing yet** shows what the scan found, its boxes greyed and ticked as syncing would take them, until its saves sync.
- **Sync**: Between your PCs or Back up only (for a game its store syncs), who wins when both PCs changed it (Newest wins, Always ask, This PC wins), and Stop syncing it, which asks first.
- Changes wait for **Save changes**; the foot says how many there are. Cancel, Esc and the close button drop them, asking first when there are some. A game's own choices travel with its saves, so its other PCs take the same files (R8).

**Built** (version 58, 18 Oct 2026; KAN-167, LIB-24): Change… shows for an installed game in its own folder with a program (not a store's game, nor a folder of the person's own such as a server's world). A program picked is checked at once and waits for Save changes, which moves the game to its folder; a refused one says why with "Nothing was changed." The check names what said so: "its GOG record", "its Steam app ID" (a `steam_appid.txt` in its folder), "its own record" (the program's name or description), or "its folder's name"; another game's reads "This is Dark Souls: Remastered's program (DarkSoulsRemastered.exe), not Dark Souls III's: its Steam app ID says so. Change… and pick Dark Souls III's own program, in its own folder." (GameSync can't know which program is the right one, so it doesn't name one); one that names no game reads "Nothing in helper.exe or its folder names a game, so GameSync goes by your pick." in a plain note; a folder another game has is refused: "Dark Souls III already has this folder, …, so it can't be Dark Souls: Remastered's too." The answer is kept for the game on this PC with the folder it was made for, and shows on Installed files and the On this PC card while the game is in that folder; a game located before this check is checked the first time its page or Properties opens.
