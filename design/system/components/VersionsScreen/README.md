Showcase of the Versions tab of the save manager: every version of every game, newest first, from every PC, so what GameSync kept lately, and why, is one look away. Built only from the components above.

- It's a tab of the save manager (Saves, Plan, Versions, Log). The top bar's right side holds two `Select`s: the game (All games, then each game by name) and the PC (Every PC, then each PC by name).
- The stat strip counts every version kept, how many are named, how many are kept (pinned: named saves, the save that lost a conflict, the save before an update or a restore), how many were made this week, and the oldest.
- One `ConsoleTable`, newest first: when it was saved, the game, the PC in `mono` capitals, why it was kept with its icon (after play and how long, after 5 quiet minutes for a folder of your own, the daily backup, the first backup, held for review, named, or kept before an update, a restore or after losing a conflict), how many files and its size. Named and kept only, in the toolbar, narrows it to the versions that stay pinned.
- A row opens that game's saves with the version picked, where Restore is and asks first: this tab only finds a version; it never restores one itself.
- The newest 100 show; Show N older loads the rest. With a filter that matches nothing, the table says why (`#empty`).
- The foot says every version is kept: all of them in the cloud, and the last 10 of each game on this PC (or all of them, as Settings keeps them).
