Short labelled facts: an `overline` label beside each value. For a game's About (Developer, Publisher, Released, Genres, Engine), On this PC, its Saves card and its Installed files.

Provide `items`, each `{label, value}`; `mono` sets a path, a build or an option in `mono`.

- Items with no value are left out, so a game shows only what's known. Never write "Unknown".
- Labels are `ink-faint`, values `ink` at 13px. A long path breaks anywhere rather than pushing its card wider.
- Genres are `gs-tag`s inside the value.
